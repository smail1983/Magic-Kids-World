# Magic Kids World 🌈✨

A colorful, safe, offline-first Flutter adventure game for children ages 5–10.

## Included in this first version

- Friendly magical home screen
- 5 themed worlds with progressive unlocking
- Mini-game hub
- Playable Color Match mini-game
- Stars, level progress and rewards
- Character reward items (hat, glasses, shoes and more)
- Daily Adventure card
- Local progress saving with SharedPreferences
- Parent Zone protected by a simple math gate
- Parent progress statistics and sound setting
- No accounts, chat, location tracking, gambling, loot boxes or real-money rewards
- Responsive Material 3 UI for phones and tablets

## Run locally

Install Flutter, then run:

```bash
flutter pub get
flutter run
```

The project is intentionally modular so additional mini-games, characters, costumes and worlds can be added without changing the overall experience.

## Safety-first design

The game is designed around short, positive sessions. There are no countdowns, streak pressure, public profiles, messaging, social feeds or manipulative notifications. Progress is stored locally on the device.
